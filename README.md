# IS 4440 – Networking & Servers Midterm Trainer

A study app for a Network+-based networking course midterm. One self-contained file; Python 3.8+ with Tkinter, no extra packages.

## Features
- Chapter quizzes covering Network+ modules 1–4, 6–8, and 12, plus frame traversal, routing tables, and subnetting
- **Exam simulation** with a Scantron-style answer sheet, flag-for-review, and a timer
- **Randomly generated subnetting problems** (network ID, mask, broadcast, equal-size subnets) with worked solutions
- Skill drills, flashcards, weak-spot tracking, and a study-guide checklist
- Every question is tagged by source (course material, practice question, or generated)

## Run it
```bash
python IS4440_Midterm_Trainer.py
```
